# Working on MemoryOS

- Start with the [README](README.md) to integrate an app or the [development guide](DEVELOPMENT.md) to work on the code.
- Run focused checks for the paths you change. Use synthetic data and dedicated local services for integration tests.
- Preserve authentication, account scope, source attribution, and visibility checks when changing memory flows.
- Keep credentials, customer data, generated evidence, and local configuration out of commits.
- Report vulnerabilities through [SECURITY.md](SECURITY.md).
